# Memory Remediation — SQLite-backed dictionaries

Goal: cut IME resident heap from ~40-80 MB to <10 MB. Prove it with before/after measurement on a 1 GB RAM emulator.

## Locked decisions
1. `.db` files git-ignored, regenerated by Gradle.
2. Ngram parser duplicated in Gradle task (sync-comment guarded); `:dictdata` module extraction deferred.
3. Low-RAM gate: `ActivityManager.isLowRamDevice`.
4. Language-toggle loading state: animated spinner + crossfade.
5. Verification: scripted `adb dumpsys meminfo` baseline + post-change + in-app `MemoryProbe` + instrumented test on the `TanaLowRam` AVD.

## Execution order
1. **Track 0** — `plans/avd-setup.md` + install cmdline-tools + create `TanaLowRam` AVD.
2. **Track 2-preface** — add `MemoryProbe.kt` (debug-only, no behavior change).
3. **Track 7a** — baseline capture: drive `TestKeyboardScreen` via `adb`, run typing script (committing + language toggle cycles), capture `dumpsys meminfo` ×3 + `MemoryProbe` log + GC logs. Write `plans/baseline-summary.md`.
4. **Track 1** — Gradle `generateDictionaryDbs` task producing `amharic.db`/`english.db`.
5. **Track 2** — `SQLiteDictionary` + `SQLiteNgramModel` + `SuggestionCache` + correctness unit test. Wire into service. Animated loading state on toggle. Delete old classes after tests pass.
6. **Track 3** — allocation pooling + prefix memoization in `Transliterator`/`CandidateRanker`.
7. **Track 4** — RAM-gated fuzzy guessing.
8. **Track 5** — narrow Compose reads in `KeyboardScreen`.
9. **Track 6** — drop `material-icons-extended`, add `AppIcons.kt`.
10. **Track 7b** — post-change capture. Write `plans/postchange-summary.md`. Verify acceptance gate.
11. **Track 7d** — instrumented memory regression test (`connectedAndroidTest`).

## Acceptance criteria
- Median PSS Total ≤ 50% of baseline.
- Dalvik Heap ≤ 35% of baseline.
- `MemoryProbe` post-dict-open `nativeHeapAllocated ≤ 15 MB`.
- All existing JVM unit tests green.
- New SQLite correctness unit test green.
- New memory instrumented test (7d) green.
- Manual smoke at 1 GB RAM: no "stuck/never dismisses," suggestions <200 ms.

## Tracks

### Track 0 — Emulator & tooling
See `plans/avd-setup.md`. AVD: `TanaLowRam`, `pixel_3a`, 1024 MB RAM, 32 MB heap.

### Track 1 — Gradle SQLite generator
- `app/buildSrc/src/main/kotlin/DictionaryDbGenerator.kt` reads gzipped TSV/binary `.dat` files, emits `app/src/main/assets/amharic.db` and `english.db`.
- Tables: `words(word TEXT PRIMARY KEY, freq INTEGER, key TEXT)` + `idx_words_key`; `vocab(id INTEGER PRIMARY KEY, text TEXT)`; `bigrams(ctx INTEGER, succ INTEGER, weight INTEGER, casing INTEGER)` + `idx_bigrams_ctx`; `trigrams(ctx INTEGER, succ INTEGER, weight INTEGER)` + `idx_trigrams_ctx`.
- `.gitignore` appended: `app/src/main/assets/*.db`.

### Track 2 — SQLite-backed runtime
- `suggestion/SQLiteDictionary.kt`: `SQLiteOpenHelper` + `OPEN_READONLY`; lazy open on first query; `suggestionEntries(prefix, limit)` via `WHERE key >= ? AND key < ? ORDER BY freq DESC LIMIT ?`.
- `suggestion/SQLiteNgramModel.kt`: `nextWordSuccessors(ctx)` via indexed SELECT (bigrams + trigrams).
- `suggestion/SuggestionCache.kt`: LRU 256 (~1-2 MB), cleared on toggle/release.
- `util/MemoryProbe.kt`: `BuildConfig.DEBUG`-guarded `log` of `Debug.MemoryInfo.getTotalPss`, `Runtime.totalMemory - freeMemory`, `Debug.getNativeHeapAllocatedSize` at: `onCreate` after dict open, after first keystroke, after language toggle. Tagged `MemoryProbe`.
- Suggestion strip shows animated spinner + crossfade when `isLanguageSwitching`.
- Delete `WordTrie.kt`, `NgramModel.kt`, `WordDictionary.kt`, `NgramDictionary.kt` after tests pass.
- Keep: `AmharicTable`, `Transliterator`, `CandidateRanker`, `EthiopicNormalizer`.

### Track 3 — Per-keystroke allocation pooling
- Memoize `Transliterator.candidateReadings` by buffer prefix (LRU ~32).
- Pool `PathCandidate` + rankKey `ArrayList<Int>` via `ThreadLocal`; reset per keystroke.
- Hoist `bestFrom` memo `HashMap`, `completionCache`, rank intermediates to service fields with `.clear()` per keystroke.
- Intern `EthiopicNormalizer.normalize` results (LRU 256).
- Single-pass sort in `rankAmharic`.

### Track 4 — RAM-gated fuzzy
- `onCreate`: `isLowRam = (getSystemService(ACTIVITY_SERVICE) as ActivityManager).isLowRamDevice`.
- Fuzzy call sites: `if (ranked.size < limit && !isLowRam)`.
- High-end: bounded SQL `WHERE key LIKE 'X%'` + in-Kotlin two-row Levenshtein.
- Low-end: skip.

### Track 5 — Narrow Compose reads
- Move `service.suggestions`/`suggestionsArePredictions`/`emailSuggestions` reads into `SuggestionArea` only.
- `remember(isAmharic, numbersMode, availableWidth, heightScale) { computeKeyboardMetrics(...) }`.
- Move `palette`, `isDarkTheme`, `enterAction`, `showNumberRow`, height-scale reads into their respective subtree composables.
- Top of `KeyboardScreen` keeps only: `isAmharic`, `numbersMode`, `keyboardHeightScale`.

### Track 6 — Drop material-icons-extended
- Remove `material-icons-extended` from `app/build.gradle.kts:138` + `libs.versions.toml:19,28`.
- New `ui/icons/AppIcons.kt` with copied official `ImageVector` definitions (Apache-2.0 attribution, comment).
- Swap imports at `SuggestionBar.kt`, `EmojiPanel.kt`, `KeyComposables.kt`, etc.
