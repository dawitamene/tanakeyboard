# Addiyon Keyboard 2.0.0

First production release.

## Google Play — English (en-US)

Welcome to Addiyon Keyboard 2.0, our first production release!

- Type Amharic with Latin transliteration and smart word suggestions.
- Switch easily between Amharic and English.
- Use voice typing, emoji, themes, a number row, and the built-in typing guide.
- Improved cursor editing and deletion so committed Amharic always stays in Fidel.
