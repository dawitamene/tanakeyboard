# Addiyon Keyboard 2.0.3

Edge-to-edge polish for Android 15+.

## Google Play — English (en-US)

This update makes the app draw edge-to-edge the way Android 15+ expects, so
the status bar and navigation bar icons stay readable on top of the Addiyon
brand background instead of disappearing into it.

- Status and navigation bar icons now flip between light and dark to match
  the system theme, so they no longer blend into the cream Paper
  background in light mode.
- The app no longer goes through AndroidX's `enableEdgeToEdge`, which still
  calls deprecated `setStatusBarColor`/`setNavigationBarColor` and sets
  `LAYOUT_IN_DISPLAY_CUTOUT_MODE_SHORT_EDGES` internally. The DEX is now
  free of those symbols.
