# Addiyon Keyboard 2.0.1

Composition fixes.

## Google Play — English (en-US)

This update fixes the cursor-move bugs in rich text fields (Gmail, Docs,
Facebook Messenger, and anything that uses Compose text fields or WebViews
for its input box) where the keyboard used to scatter random characters
and lose spaces the user typed. The keyboard also stops stripping spaces
when a word is underlined (spell-check, autocomplete, or rich text
composing span).

- Cursor moves into the middle of a run-together word now split it cleanly:
  "coolbree" with the caret between the two halves becomes "cool bree"
  on space, instead of leaving garbage throughout the field.
- Putting the caret back at the end of a word and typing continues that
  word with the correct suggestions, instead of starting a new one.
- Tapping a suggestion chip replaces the word it was offered for in every
  field, including rich text editors where it used to silently do
  nothing.
- The suggestion strip no longer flashes the toolbar icons between words
  or between keystrokes.
