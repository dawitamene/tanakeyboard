# Oromo language pack data status

The initial pack implements the `om-ET` Latin input contract, casing, apostrophe word boundaries,
layout, subtype identity, and product wiring. It intentionally ships without a dictionary or
n-gram corpus. No source with approved redistribution terms was supplied for this migration, so the
suggestion engine returns an empty result instead of packaging unlicensed or mislabeled data.

Add a corpus only after recording its source, license, normalization rules, locale coverage, and
generated database manifest here.
